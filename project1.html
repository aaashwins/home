Retail Operations & Inventory Control

Supermarket Stock Variance & Analytics

An end-to-end operational intelligence platform monitoring physical stock audits, wastage patterns, and inventory shrinkage.

Project Overview & Data Pipeline

This retail analytics system bridges physical stock auditing data with POS transactional records to pinpoint stock shrinkage, damaged inventory loss, and high-variance departments. Designed for store operations and category managers, it highlights stock discrepancies between system records and physical shelf counts.

Technologies Used

SQL Server / Views Python 3.11 Streamlit Power Query Plotly Express DAX / Modeling

1. Stock Reconciliation Engine

  • System vs. Physical: Calculates variance quantity (`Diff_Qy`) and total value loss (`Diff_Value`).
  • Departmental Breakdowns: Tracks variance distributions across high-turnover categories.
  • Shrinkage Index: Flags departments exceeding allowable inventory variance thresholds.

2. Wastage & Damage Analysis

  • Categorizes loss drivers between expired merchandise, store damages, and inventory uncounts.
  • Quantifies monthly financial leakage across high-risk store locations.
  • Automates re-order suggestions for high-turnover grocery lines.

3. Anonymization & Data Security

  • Masked Barcodes: Converted raw identifiers to `bigint` sequential keys.
  • Scaled Financial Values: Financial figures scaled using decimal multipliers to protect exact commercial margins.
  • Generic Naming: Standardized product descriptors to protect vendor trade secrets.
